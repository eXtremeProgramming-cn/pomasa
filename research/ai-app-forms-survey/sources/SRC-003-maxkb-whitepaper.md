# MaxKB 企业级智能体平台（第 11 章提取）

## 定位与演进路径

MaxKB（Max Knowledge Brain）的设计初衷：解决企业拥抱 AI 的技术门槛高、部署成本高、迭代周期长。**渐进式升级路径：知识库问答（RAG）→ 复杂业务流程自动化（Workflow）→ 智能体（Agent）**。从最基础、最易落地的知识库问答开始，逐步扩展到复杂业务流程和自主决策。

## 核心能力

1. **RAG 管道（核心架构）**：多源知识库摄取（拖拽文件、Web 站点自动爬取）→ 自动文档处理（分段 Segmentation → 向量化 Vectorization → 存储于向量数据库如 PostgreSQL）→ 命中处理两种模式：
   - 模型优化（Model Optimization）：命中分段 + 用户问题一起发给大模型生成答案（复杂问答）。
   - 直接回答（Direct Answer）：相似度达标直接返回命中分段原文（制度查询、规格手册，保精确性）。
2. **工作流引擎（Workflow）**：拖拽式编排，非技术人员可定义复杂业务流程，串联大模型、知识库检索、外部工具调用。
3. **工具调用（Tools）**：两类，Python 函数工具与 MCP 服务工具；可查询数据库、发邮件、调第三方 API，赋予 Agent 能力。
4. **模型中立**：本地私有化（Llama、Qwen）、国内公共（DeepSeek、通义、混元、豆包、千帆、智谱）、国外（OpenAI、Anthropic）。
5. **零编码嵌入与开放 API**：嵌入网站、企业微信、钉钉、飞书；AI 能力通过 API 对外开放，供业务系统调用。
6. 在线应用市场（工具开箱即用）。

## 对本文档的意义

- 典型"RAG 知识库问答 → 低代码工作流 → Agent"三步演进形态的代表，与其渐进式叙事一起构成一个形态簇（知识库问答形态）。
- 注意其中的"确定性软件"成分：分段、向量化、相似度检索（PostgreSQL）、直接回答模式全部是确定性机制；LLM 只在"模型优化"命中模式中承担生成，且被检索结果严格约束。这正是"确定性内核 + 概率智能在检索边界内活动"的实例。
- MCP 已被纳为工具接口标准之一。
