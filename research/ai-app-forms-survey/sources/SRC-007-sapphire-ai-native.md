# Sapphire AI-Native 应用框架（全文提取）

## AI-Native 定义（四条）

1. 建立在基础 AI 能力之上（从大数据学习、理解上下文、生成新输出）。
2. 交付突破传统速度/规模/成本约束的成果，开启全新可能。
3. 设计用于持续改进：底层模型进步 + 用真实数据反馈循环精化。
4. 包含某种专有 AI 技术成分（微调开源模型、模型编排），而非 100% 现成组件。

## 五维评估框架

1. **Design（设计）**：
   - 新交互模型：chat/search 界面向 co-creation canvas（OpenAI Canvas）、co-pilot 向 auto-pilot（Anthropic computer use）演化；多模态输入输出。
   - 加速反馈循环：up/down 评分、human-in-the-loop 审阅、意图信号采集（分享、停留、复制）。
   - 开发 AI-Native 系统：商品化组件与专有能力的平衡（微调/RAG/prompt engineering 组合）；可解释性嵌入多步骤（cite 具体内容、置信区间、深层解释）。引用 Abridge CTO：区分"哪些部分开源模型能做、哪些值得微调"。
2. **Data（数据）**：端到端数据管理严谨性、激活潜在数据（Box/Drive 沉睡文档、通话记录）、创造新的专有数据集（多模态参与数据、生成内容元数据）。竞争从"数据量"转向"数据质量、隐私与应用"。
3. **Domain Expertise（领域专长）**：把领域活动翻译为 AI 加速的工作流（对话转写、研究输入摘要、关系理解）；大规模快速综合（法律领域 Harvey、EvenUp、Robin AI）；全球知识 + 领域知识 + 组织知识的结合。
4. **Dynamism（动态性）**：实时优化价格/性能权衡（模型路由器如 Martian）；生成式客户旅程；多层级超个性化（带共享记忆的 agents 是最终形态）。
5. **Distribution（分发）**：定价与包装灵活（嵌入现有服务、溢价 SKU、独立应用、按效果付费）；新商业模式（按对话计费 Salesforce Agentforce 每会话 2 美元、按解决票据计费 Sierra/MavenAGI、按产出计费 Synthesia 每分钟视频）。

## 对本文档的意义

- 提供了产业资本视角的"AI-native 应用"定义与评估维度，可作为形态分类的补充轴（设计/数据/领域/动态性/分发）。
- 关键洞察："app 层与模型层分化"（Apps = 模型编排 + 领域 UI + 功能面）；agents with shared memory 是最终形态。
- human-in-the-loop reviewers 是"人"位置的理论承认；可解释性与引用（cite、置信区间）对应可验证血缘。
- 该框架是"评价投资标的"的，非"工程架构"分类；我们更需要的三机制接口分类仍需自建。
