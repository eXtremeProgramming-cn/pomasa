# 浏览器 Agent 生态（全文提取）

## Browser Use

- YC 2025 冬季班，创办人 Magnus Müller 与 Gregor Zunic（苏黎世联邦理工加速器）。
- 把网站按钮与元素拆解成更像文本的格式给智能体用，帮 AI 智能体搞清网页选项并自主决策。与纯视觉截图方案相比，成本更低、可反复运行。
- 场景：填表、搜索、导航、加购物车结账、读简历找工作、按许可过滤 Hugging Face 模型并排序保存。
- GitHub 4.7 万 star 以上。

## MCP 之后的时间线

- 2024 年 11 月 Anthropic 提出 MCP（类似 AI 应用的 USB-C）。
- 2025 年 1 月 OpenAI 推出 Operator：用 Computer-Using Agent（CUA）通过视觉界面控制网页浏览器，模拟人点击、输入、滚动；复杂界面或验证码时需用户介入。
- 同期 Browser Use 开源并被 Manus 集成；Manus 以综合能力与实时显示思考过程的界面走红。

## 对本文档的意义

- 浏览器 Agent（CUA/Browser Use/Operator/Manus）是"概率智能直接操纵人类界面"的形态：不是把能力做成 API 给 AI 调，而是让 AI 照着人的方式用浏览器。确定性部分（网页 DOM 结构提取、浏览器控制）变成给 AI 的"眼镜"。这也印证"AI 与确定性软件接口"的另一种形态：人用界面与 AI 用界面的界面重合。
- "需要用户在验证码/复杂界面时介入"是人类 checkpoint 的又一实例。
- 工作区规则：本素材落盘备查。
